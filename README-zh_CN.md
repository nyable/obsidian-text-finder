# Obsidian 文本查找器

[English](README.md)  
[中文说明](README-zh_CN.md)

这是一个用于 Obsidian 的插件（https://obsidian.md）。  
提供类似于 VSCode 的搜索窗口：编辑模式支持查找与替换，阅读模式支持查找所呈现的正文。

## 功能

在 **编辑模式** 下搜索或替换当前 Markdown 文件的文本，在 **阅读模式** 下搜索当前笔记的阅读正文。

-   在当前文件中搜索/替换
-   高亮匹配文本
-   显示匹配数量
-   支持正则表达式
-   支持区分大小写
-   支持全字匹配
-   编辑模式下在精确选区内查找／替换，支持多个选区
-   输入历史

# 如何使用

## 安装

### 社区插件

-   在社区插件市场中搜索"text finder"并安装。
-   在 Obsidian 设置中启用插件。

### 使用 BRAT 安装

-   [安装 BRAT 插件](https://obsidian.md/plugins?id=obsidian42-brat)。
-   执行命令 `Obsidian42 - BRAT: Add a beta plugin for testing`。
-   粘贴此存储库的 URL 并确认。
-   在 Obsidian 设置中启用插件。

### 从 Release 安装

-   在 [最新发布版本](https://github.com/nyable/obsidian-text-finder/releases/latest) 中下载 `main.js`、`styles.css`、`manifest.json`。
-   将 `main.js`、`styles.css`、`manifest.json` 复制到你的 vault 的 `VaultFolder/.obsidian/plugins/text-finder/` 中。
-   在 Obsidian 设置中启用插件。

## 基本使用

-   在 Obsidian 的快捷键设置中，为 Text Finder 命令分配快捷键。
-   在当前笔记执行“在当前文件中：打开查找”，输入文本，用上下项按钮或 Enter 跳转匹配。
-   编辑模式下可执行“在当前文件中：打开查找与替换”。按 Escape 或关闭按钮隐藏窗口。
-   各关闭命令行为一致。默认保留输入及正则／大小写／全字匹配选项；“清空查找和替换文本”同时清空两个输入框，不重置选项。窗口隐藏后 Escape 不再影响查找器。

## 常规设置与悬浮搜索入口

- “常规”页新增“打开笔记时显示悬浮搜索入口”，默认关闭。启用后，已打开的笔记和之后打开的 Markdown 笔记显示小搜索图标，不自动搜索、滚动或抢焦点，也不唤起键盘。同文件双分屏各自独立。
- 单击小图标展开，不聚焦输入；“显示／切换查找”快捷键则展开并聚焦查询，保留已有输入和选项。“打开查找与替换／切换替换区域”从小图标或关闭状态打开完整框、确保替换栏显示并聚焦替换输入；完整框已展开时，切换命令才正常切换显示／折叠。
- 主动关闭后，切回同一标签不会重新出现；打开另一篇笔记可重新显示。已经展开的搜索框不会被打开默认强制收起。关闭设置只停止后续自动显示，不强制关闭现有入口。阅读模式仍遵守原生查找偏好及不兼容回退，替换命令不切换到编辑模式。

## 全字匹配

- 点击正则和大小写选项旁的“全字匹配”按钮。默认关闭，统一作用于编辑查找、阅读查找和编辑替换，可与正则组合使用。
- 边界采用 VS Code 默认的编辑器分隔符规则，不是 JavaScript `\b`，也不进行自然语言分词。`cat` 可以匹配 `(cat)`、`cat-dog`，不会匹配 `cat2`、`cat_name` 或 `concatenate`。
- 中文不自动分词：`中文` 不匹配 `中文内容` 中的局部文本。全角标点和 NBSP 不属于默认分隔符。
- 匹配自身首尾的分隔标点也可满足对应边界，例如 `C++` 也能匹配 `C++17`。正则按实际完整匹配检查，不改变捕获组或替换模板。
- 阅读查找检查连续的渲染正文，不以 DOM 节点划分词边界，因此结果可能与 Markdown 源码查找不同。降级到原生查找时仍采用 Obsidian 自身语义。

## 在选定内容中查找

- 在编辑器选择文字，执行“在选定内容中打开查找”，或打开查找框后，在“更多”中开启“在选定内容中查找”。独立命令保留已有查询；普通打开查找仍遵守“将所选内容用作搜索文本”。可在外观设置中把范围按钮设为常驻／更多／隐藏，没有默认开启或跨行扩展整行设置。
- 范围严格限定选中的源码字符，包括跨行选区；不扩大到完整源码行。多个非空选区分别搜索，不搜索中间空隙，也不拼接选区文字。计数、上下项、单次替换与全部替换共用范围。
- 开启状态以选区按钮激活为准，正文只以淡背景标明范围，不加下划线或结果旁文字。按钮放在“更多”时，收起的“更多”右上角显示强调色圆点，展开后隐藏圆点；隐藏按钮不另加标记。导航选中匹配不会缩小范围；重新选择后再次执行独立命令可更新范围，关闭范围开关恢复全文查找。仅在正文重新选择不会自动更新范围。范围为空／失效时仍保持限制和按钮激活，按钮提示需重新选择或关闭限制。
- 编辑会移动范围，范围内及边界处的插入／替换包含在新范围中。只删除整个范围时保留空锚点，撤销可恢复；删除跨过范围边界时使受影响范围失效，不猜测或扩大边界。空／失效范围不执行替换。
- 收起保留范围；关闭结束范围会话，并阻止该会话的隐藏替换命令退回全文写入。明确重新打开普通查找后开始全文会话。换文件、切阅读模式、编辑器重建或窗口迁移使范围失效，需重新选择或明确清除范围；范围不持久化，同文件双分屏独立。
- 正则从各范围起点在完整原文上扫描，仅保留完整落在该范围的匹配。前后顾、行锚点、全字边界及替换的原文前缀／后缀仍使用全文上下文：在 `foobar` 中只选 `bar`，`(?<=foo)bar` 可以命中，`^bar` 不会因为选区起点变成行首。范围不是独立字符串，不能承诺与 VS Code 的全部正则行为一致。
- 编辑模式使用源码／实时预览中的 Markdown 源码选区；阅读模式使用渲染正文选区，只查找、不替换，两种坐标不互转。请在正文渲染完成后选择并启用；阅读正文改变或节点重建时范围失效，不静默回到全文。

“更多”展开为紧凑图标按钮面板，按钮与外部工具栏外观一致；模式切换后保持展开，可连续调整，普通操作执行后收起。面板内任一模式开启时，收起的“更多”以右上角 5px 主题强调色圆点提示，不使用模式激活蓝底／边框；展开后隐藏圆点，仅保留轻微展开边框，收起时按当前状态恢复。圆点不占布局、无动画、不独立响应点击，读屏开启模式说明在展开时仍保留。工具栏额外焦点框仅使用 `:focus-visible` 显示，鼠标／触屏不保留蓝色焦点阴影，模式自身激活样式不变。点击外部、再次点击“更多”或按 Escape 收起，Escape 不同时关闭查找框。方向键及 Home／End 浏览可用按钮，Tab 保持原生焦点导航。

### 搜索选区外观

在 **设置 → 外观 → 搜索选区** 中自定义背景颜色、边框颜色（均支持透明度）、轮廓边框开关和 1–3px 粗细。默认跟随主题淡背景、主题强调色，边框关闭，粗细 1px。颜色草稿只预览，应用后更新正文；单项恢复继续继承主题／CSS，分组恢复只重置搜索选区，不影响匹配颜色或工具栏。

背景颜色始终可见，“显示轮廓边框”位于边框设置之前；开启后才显示边框颜色和粗细，关闭保留已选值并关闭关联弹出面板。轮廓左右仅补偿半线宽，内缘贴近选中文字边界，不另留 2px；上下仍保留约 2px 内侧间距。狭窄间隙按分离方向限制外扩，不增加正文 padding 或改变范围。

边框沿当前已渲染选中文字的外轮廓绘制，不用整块大矩形包围跨行首尾之外的内容；高亮／语法片段合并轮廓，不把多选区之间的空隙连起来。自动折行／滚动后重测，隐藏源码或不连续文字可呈现分离轮廓。它不参与点击、不改变字符布局，也不扩大实际查找／替换范围。旧宿主若缺少 CodeMirror layer API，仅保留背景。

同一连续范围内完整选中且可见的普通空白行（含空格／Tab）会补充轮廓连接，优先采用上下文字共同宽度，不扩成编辑器整行大框；隐藏／折叠源码、独立选区及有歧义的双向文字片段仍保守分离。编辑模式的匹配若包含真实换行，会在已匹配的行尾显示小型 `↵`，沿用普通／当前匹配颜色；连续换行仍按原匹配计数。不改变正文、自动折行或复制内容，阅读模式不添加源码换行标记。实际主题、引用／列表、实时预览和移动端绘制需实机验收。

## 移动与贴边收起查找框

- 桌面编辑／阅读模式均直接拖动左侧装饰条，折叠箭头只折叠替换行；移动端使用结果栏顶部中央的小横条，拖动区域大于横条本身，不必从屏幕侧边拖拽。约 3px 位移就启动，无需长按。实际拖动时整框透明度 80%，松手／取消恢复；移动入口保留读屏名称、不显示悬浮文字。
- “常规”设置的“拖到边缘时自动收起”默认关闭。开启后拖近左右边缘松手收起；接近满宽时用明确横向拖动，上下移动不收起。紧凑标记桌面 30px／移动端 40px，可直接二维拖动：靠边松手吸附，不靠边保持收起并停在原处。拖动不展开，单击展开不唤起键盘；桌面右键菜单提供关闭／恢复，移动端长按不弹菜单也不误展开，按住后仍可拖动。移动端可展开后关闭，恢复位置使用命令／常规设置入口；输入框长按选词不受影响，关闭命令及 Escape 沿用原规则。
- 收起保留输入、选项、当前项、替换行状态和高亮；替换计算期间不自动收起，贴边执行替换先展开显示进度。满宽展开时居中并保留高度。滚动、鼠标离开、尺寸变化不会触发自动收起。
- 移动端“更多”仍在输入右侧，只有放不下的常驻按钮移到结果栏，保留顺序和设置，宽度恢复后回流。结果栏可换行，不裁切控件。
- 移动端结果栏与单行搜索框采用一致的基础高度；查找／替换输入明确行高和内边距，保留多行及长文本滚动，不强制隐藏内容。
- 收起入口使用主题次级背景、正文色图标及柔和圆角。自动显示时初始靠安全边界（默认右侧），不需要开启拖边自动收起；手动拖到中间后仍可保持悬浮，不因切回标签强制贴边。
- 移动端拖动仅在小图标／中央手柄上隔离宿主滑动，正文左右滑动及输入框触摸仍正常；拖动支持尽早指针捕获和局部触摸保护，不需要长按。
- 聚焦移动入口后可用方向键移动 8px（Shift 为 32px），Home 恢复位置；另有恢复位置命令（当前视图）和常规设置入口（已有视图）。位置仅在会话内保留，限定于所属笔记视图及可见视口，不写入磁盘。

## 阅读模式查找

- 支持“在选定内容中打开查找”和工具栏范围开关，保留已有查询；重复文本按实际 DOM 位置区分，点击输入框或导航不会缩小已锁定范围。空查询保留选区背景／可选轮廓；虚拟分块挂回恢复显示，关闭解除范围。显式选区命令不可降级为原生全文搜索。
- `<br>`、代码块内换行及正文块间逻辑边界可匹配并显示 `↵`，纯换行也可导航；连续换行属于一次匹配仍计一项。保护分隔符、索引末尾补齐符和自动折行不冒充正文换行。范围背景及轮廓沿用外观配置，仅测挂载正文，未知段落空隙不强连；实际宿主主题／移动端效果待验收。

-   在阅读模式执行“打开查找”，支持大小写敏感、全字匹配、正则、高亮和匹配导航，不支持替换。
-   搜索阅读正文，不包含隐藏的 Markdown 标记；嵌入笔记及部分插件生成的内容暂不支持。
-   升级后如仍使用原生查找，请关闭“阅读模式下使用 Obsidian 搜索”设置。

## 正则表达式替换

查找、替换候选及替换后重算优先在 Worker 中计算；等待时可关闭查找器来终止。Worker 启动不可用会提示并回退同步兼容模式；执行中故障不会自动重跑，可重试或明确选择同步重试。同步模式的复杂正则可能阻塞界面。**正文写入仍为同步事务，全部替换可一次撤销；提交后取消不会撤销正文，失败重试不会重复已完成的替换。** 阅读 DOM 索引、结果处理及绘制仍在主线程。不限制现有正则语法或匹配数量。

开启正则表达式模式后，可以在替换文本中引用捕获组。例如，查找 `(foo)(bar)`，
替换为 `$2-$1`，结果为 `bar-foo`。

-   使用 `$1`、`$2` 等引用捕获组，`$<name>` 引用命名组，`$&` 引用匹配文本，`$$` 插入美元符号。
-   启用转义字符设置时，正则替换中的 `\n`、`\t` 分别转换为换行和制表符；`\\` 插入字面量反斜杠。
-   普通文本模式下，替换内容按字面量处理，不展开美元符号模板或反斜杠转义。
-   当前查找与替换仍排除零宽匹配，例如单独使用 `^`。

## 分屏使用

-   每个查找器只操作其打开时所属的 Markdown 视图。分屏视图（包括同一文件的两个视图）分别维护当前匹配项。
-   在该视图打开另一文件时，保留查询文本并更新结果。
-   修改正文后更新匹配，不自动改变阅读位置；替换仅适用于编辑模式。

## 搜索历史

-   通过“显示搜索历史”命令查看、复用、复制或删除查询，搜索框中可用上下键切换历史。
-   保留查询中的首尾空格、换行和制表符。同一查询连续导航只计一次使用。
-   正在浏览的历史项被删除后，转到下一个仍存在的邻近项，末尾则转到前一项；历史清空后恢复浏览前的输入。
-   最多保存 1–200 条，可按创建时间、最近使用时间或使用次数排序；降低上限会移除低优先级记录。
-   禁用历史后保留已有记录，但停止记录新查询、统计使用情况和上下键历史导航。
-   保存或读取失败时会显示提示。请按提示处理；未保存的修改可能在退出后丢失。

## 外观设置

- 在“外观”设置页的独立按钮配置块中调整顺序及常驻／更多／隐藏，顶部完整预览固定可见，下方配置独立滚动；预览固定展开查找和替换两行，不支持任何操作。
- 颜色、搜索选区、搜索栏按钮、替换栏按钮四个分组可独立折叠，默认全部折叠。分组标题旁的回退图标提示“恢复默认设置”；点击直接恢复对应分组，颜色单项恢复仅影响该项，无确认弹窗，完成后统一提示“已恢复默认设置”。
- 预览查找框使用固定示例词 `text`，替换框保持空白；下方仅一个两行英文文本区域，同时展示当前匹配、其他匹配及跨行搜索选区；窄屏自然折行，不裁切或缩小字号。
- 可设置聚焦边框、左侧装饰条、普通／当前匹配的背景和文字颜色。点击色块打开颜色与透明度选择面板，调色仅预览；点击“应用”才生效并保存，取消或离开设置会丢弃草稿。未自定义项目继续继承现有 CSS；单项或颜色分组恢复移除覆盖，不改变工具栏配置。
- 在正则表达式、区分大小写、全字匹配对应项中设置“默认开启”。仅作用于各 Markdown 视图新建的查找器；已有查找器以及关闭重开、切换文件／模式时保留手动选择。精确的旧默认布局升级后将三个匹配选项放在一起；自定义顺序及显示位置继续保留。
- “恢复默认设置”只作用于所在栏：搜索栏恢复按钮布局并关闭三个默认开关，替换栏恢复按钮布局；不改变已有查找器的选项。隐藏按钮不会关闭对应模式。

```css
body {
	--nya-match-bgColor: #ea5c0054;
	--nya-match-color: inherit;
	--nya-match-curbgColor: #ffcc00;
	--nya-match-curColor: #000000;
}
```

### 匹配高亮与当前项（编辑模式）

```css
.nya-text-finder-match {
	border-radius: 2px;
	box-shadow: 0 0 0 1px rgb(60, 115, 75);
	background-color: inherit;
	color: inherit;
}

.nya-text-finder-match-current {
	box-shadow: 0 0 0 1px rgb(187, 187, 187);
	background-color: rgba(255, 170, 0, 0.8);
	color: black;
}
```
