# 阅读模式查找：真实应用验收

以下步骤必须在 Obsidian 中执行；jsdom 不验证布局、CSS Highlight 绘制或私有接口实际滚动。
建议使用临时测试库，安装 `dist/` 中的三个产物，关闭“阅读模式下使用 Obsidian 搜索”。
复制 [测试笔记](../tests/fixtures/reading-search.md)，并在尾部之前加入足够长的正文。命令均在仓库根目录执行。

## 发布门槛

- [ ] 首次打开长文、未滚动到底时，搜索 `tail-only-cat` 得到完整数量并直接定位。
- [ ] 搜索 `cat` 后反复滚动首尾；重新进入视口的匹配仍有高亮，当前项样式正确。
- [ ] 连续上一个／下一个导航，尤其首次导航到离屏块，数量、高亮和滚动目标一致。
- [ ] 输入 `hello world` 可跨加粗／斜体／代码着色节点匹配，不修改正文 DOM，不影响链接点击或复制。
- [ ] 大小写选项与正则前后顾、行首／行尾、跨块查询符合 [阅读文本规则](reading-mode-search.md#阅读文本规则)。
- [ ] 行尾空白不会制造匹配；三个表格单元格中间为空时仍有两个制表符分隔。
- [ ] CSS `display:none`／`visibility:hidden` 内容排除；折叠标题、列表、Callout 正文仍能搜索，导航展开必要祖先。
- [ ] 搜索期间发生重渲染，用户的定位请求不被后台重算取消；后台重算本身不自动滚动。
- [ ] 5 秒内未完成渲染时显示超时和原生查找入口；完成后重试恢复，不残留高亮。
- [ ] 定位／Highlight 接口运行失败显示错误而非“无结果”；使用原生查找按钮关闭插件面板。
- [ ] 同文件双分屏独立导航；关闭一个视图不清除另一个视图高亮。
- [ ] 弹出窗口与窗口迁移后使用所属 Document，高亮、模式监听与 Escape 正常。
- [ ] 打开其他文件、外部修改、撤销重做、切换模式后不复用旧文档结果。
- [ ] 反复打开／关闭查找及标签页，插件卸载后无残留 Observer、计时器、事件和高亮。
- [ ] 默认主题、至少一个常用主题、目标 Android／iOS 环境分别记录通过或未验证。
- [ ] 原生查找偏好保留；由插件回退原生时不会同时留下两套查找面板。

## 性能与已知边界

- 使用 100／1,000／5,000 块、不同匹配密度记录首次索引、连续输入、导航与滚动体验。
- 命令 `node tests/reading-benchmark.mjs` 仅提供 jsdom 逻辑基准，不代表真实 Obsidian 性能。
- 正则仍同步执行，灾难性回溯不能被渲染超时中断；不要在真实库中使用危险模式做压力测试。
- 分块 CSS 依赖祖先或相邻兄弟时，离屏节点的 computed style 可能不同；需专门检查所用主题。
- 公式、图表、嵌入笔记、Dataview 和任意第三方动态输出仍不承诺全文兼容。
