# 阅读模式查找设计

## 目标与代码边界

阅读模式搜索当前笔记所呈现的正文，而不是 Markdown 源码。共享面板、大小写与正则选项、历史和导航；不替换、不写入文件、不切换编辑模式。两种模式的匹配数量允许不同。

- [`SearchBox.svelte`](../src/SearchBox.svelte) 负责 UI 与操作入口。
- [`editor-extension.ts`](../src/editor-extension.ts) 管理视图、命令及适配器生命周期。
- [`reading-text.ts`](../src/reading-text.ts) 建立逻辑文本与文本节点偏移映射。
- [`reading-search.ts`](../src/reading-search.ts) 负责完整渲染等待、匹配、高亮和定位。

## 完整索引与私有接口

公共 preview API 无法枚举被虚拟化移出页面的分块。实现集中使用 `previewMode.renderer` 中的分块、渲染状态、`onRendered`、`showSection`、`applyScrollSection` 和 `updateVirtualDisplay`。

接口形状曾对照 Obsidian 1.14.4 的实现，但尚不代表运行验收通过。缺少接口时拒绝执行局部 DOM 搜索，不把视口结果冒充全文结果。

全文就绪要求渲染文本与当前视图数据一致、解析与渲染结束、所有分块已渲染。索引使用完整分块 DOM，包括离屏节点，排除页眉与页脚。没有单独重渲染整篇 Markdown，避免重复触发第三方处理器。

## 阅读文本规则

- 加粗、斜体、链接显示文本等行内节点连续拼接，可跨节点匹配。
- 段落／块边界使用合成换行；`<br>` 保留硬换行，连续硬换行不合并。
- 表格单元格边界使用制表符；连续空单元格保留分隔。
- 普通 HTML ASCII 空白折叠为一个空格，行尾待定空白丢弃；NBSP 不按 ASCII 空白折叠。
- `<pre>` 内部文本保留原始空白；视觉自动换行不产生文本换行。
- 实体由 DOM 提供解码后的文本，偏移保持 UTF-16，不通过小写化整个文本实现大小写不敏感匹配。
- `findTextOffsets()` 使用 JavaScript 正则；正则模式使用多行锚点，前后顾基于整个逻辑文本，排除零宽匹配。
- 没有实际正文端点、只覆盖合成分隔符的匹配不计数。
- 明确隐藏内容、嵌入笔记、属性控件、公式、图表、Dataview/DataviewJS 与阅读控件排除。折叠列表和 Callout 的正文保留。

规则是当前支持范围，不是对任意主题、HTML 或第三方生成内容的完整可见性模拟。特别是离屏 CSS 依赖祖先／兄弟选择器、CSS 伪元素文字、图片和 Canvas/iframe 内容，不承诺一致。

## 稳定端点与高亮

逻辑匹配保存文本节点和节点内数字偏移，不长期缓存可变 DOM Range：节点移出父容器时，Range 会塌缩，重新挂载不会自动恢复。

高亮只为挂载分块创建临时 Range。虚拟化移动触发重新绘制，而不重新全文匹配；正文或相关属性变化使索引失效。单个 MutationObserver 同时监听阅读根和离屏分块，相关属性包括 `class`、`style`、`hidden`、`aria-hidden` 和 `open`，主题变化也触发失效。

使用所属 Document 的 CSS Custom Highlight API。文档级注册表合并多个视图拥有的 Range，普通匹配优先级低于当前项；关闭一个视图时仅移除该视图的所有权。

阅读高亮使用 `::highlight(nya-reading-matches)` 和 `::highlight(nya-reading-current)`，复用 `--nya-match-*` 颜色变量。编辑模式的 class 样式不会自动应用，边框、圆角等效果受该 API 的样式能力限制。

## 导航、请求与等待

请求绑定所属视图、文件、渲染器及精确查询选项。同查询后台刷新可替换结果回调，但保留等待中的用户定位、当前项与导航方向；切文件、改查询、切模式和关闭操作使旧请求失效。

导航先展开匹配所属分块并挂载第一文本端点，再展开必要的列表／Callout／details 祖先，最后创建 Range 定位。折叠状态不会自动恢复。跨块匹配仅绘制当前挂载部分。

渲染回调之后用微任务检查就绪状态，同时提供最多 5 秒、约 100 毫秒间隔的可取消检查。超时或运行失败清理状态并返回明确错误，面板提供重试与原生查找入口。

## 生命周期与错误边界

- 视图关闭和插件卸载释放 Observer、计时器、端点映射、高亮所有权与 Escape 监听。
- 窗口迁移重建所属文档的索引／高亮，不复用全局窗口对象。
- 私有定位方法和 Highlight 操作异常被捕获；定位返回失败不作为成功导航发布。
- 不支持环境下“打开／切换查找”提示并回退原生查找；运行失败与超时提供用户主动降级入口。
- 原生查找偏好保留；新安装默认使用插件阅读查找，升级用户已有 `true` 值不会自动改写。

## 性能与验证边界

索引和查询结果可复用；匹配端点按分块分组，绘制只为挂载块创建 Range。首次全文索引仍为同步执行，大文档可能有明显延迟。

正则也同步执行，灾难性回溯不能被渲染等待超时中断。Worker 隔离尚未实现，防抖不等同于执行超时保护。

自动测试、基准和真实应用检查见 [测试文档](testing.md) 与 [验收清单](reading-acceptance.md)。桌面绘制、真实滚动、主题与移动端需分别验证，不能由 jsdom 通过推定。
