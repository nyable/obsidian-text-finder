# 历史记录与存储

实现入口：[历史控制器](../src/history.ts)、[设置规范化](../src/settings.ts)、[保存队列](../src/save-queue.ts) 与 [插件持久化入口](../src/main.ts)。

## 查询身份与使用统计

- 历史身份为精确文本，保留首尾空格、换行和制表符；纯空白有效，空字符串不记录。
- 同一查询连续导航只增加一次使用次数，后续更新最近使用时间。A → B → A 开始新的使用周期。
- 明确复用历史计一次；紧接的导航不重复计数。复制成功后才记录使用；异步复制完成不能复活已删除条目。
- 禁用历史保留已有记录并允许查看、复制、复用和删除，但停止记录、使用统计和上下键历史导航。

## 容量与排序

容量为 1–200，输入按 Enter 或离开后提交，不接受部分数字或无效值。缩容立即按当前排序保留高优先级记录。

支持创建时间、最近使用时间和次数排序。相同优先级按最近使用时间、创建时间和精确文本形成稳定顺序。界面选中项以精确文本而非列表下标标识，以免统计更新重排后选错对象。

## 迁移与规范化

旧格式和混合格式逐项校验。精确文本重复项取最早创建时间、最近使用时间和最大计数；设置字段也做合法性检查。旧记录中已经裁掉的空白无法恢复。

规范化结果应保持幂等，默认数组相互独立；不能因为对象字段顺序不同误判为迁移。

## 保存与失败处理

设置和历史通过独立快照串行保存，不把异步保存纳入匹配导航的等待链。

- 保存失败保留内存修改并节流提示；下次修改尝试保存最新状态。
- 没有自动后台重试，也不保证应用强制退出时落盘。
- 无法读取已有数据时禁止写入，避免覆盖用户数据。修复后重载插件；读取失败期间的临时修改不会在重载时合并。
- 单次保存失败不能阻塞队列后续任务。

## 视图隔离与替换安全

Finder 绑定所属 Markdown 视图。同文件双分屏分别维护当前项；打开另一文件保留查询但重新匹配，不复用其他文档坐标。

编辑模式高亮绑定具体 CodeMirror 文档，正文变化立即使旧高亮失效。隐藏面板可执行编辑模式替换命令，但写入前必须重新匹配。已关闭视图或阅读模式不是替换目标。

单次替换的工具栏按钮、替换框 Enter 与命令采用相同定位规则：完成替换后重新匹配；匹配数量未变时前进一项，否则定位重新匹配后的当前项。未执行替换或写入期间切换文件／编辑器时，不额外前进。全部替换不采用该前进规则。

## 正则替换规则

查找与替换共享大小写选项、多行锚点和全文前后顾。替换模板遵循 JavaScript 规则：`$1`–`$99`、`$<name>`、`$&`、`$$`、`` $` `` 和 `$'`。启用转义字符设置时处理 `\n`、`\t` 与 `\\`；普通文本替换按字面量处理，零宽匹配排除。

反斜杠转义只解析一次；未知转义、末尾反斜杠与真实的 `U+0000`（NUL）字符保留，不以用户字符充当解析哨兵。

替换计算基于一次原文快照，不在截取的匹配文本上重新执行正则，也不递归展开替换结果。相关回归见 [测试文档](testing.md)。
