## 文档分工

- README 回答用户“有什么功能、如何使用、有哪些限制”。
- `docs/` 保存实现、维护、测试与验收说明；变化时与对应代码一起更新。
- `tests/` 保留可执行测试、诊断脚本与测试样例，不承载开发说明文档。
- API 形状检查和自动测试通过不等于真实应用验收通过；未验证的平台应明确标注。
